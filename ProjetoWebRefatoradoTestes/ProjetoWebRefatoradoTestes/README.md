# ProjetoWebRefatoradoTestes

Projeto de testes JUnit criado para a Etapa 7 do Projeto Integrador.

## Objetivo
Validar regras de negócio do sistema refatorado da etapa anterior.

## O que foi implementado
- Testes unitários com JUnit 5.
- Teste de cálculo simples na classe `CalculadoraEstoque`.
- Teste de validação da regra de preço no `ProdutoService`.
- Plano de testes separado na pasta da entrega.

## Como executar no NetBeans
1. Abra a pasta `ProjetoWebRefatoradoTestes` no NetBeans.
2. Aguarde o carregamento do Maven.
3. Clique com o botão direito no projeto.
4. Escolha `Test`.

## Estrutura principal
- `src/main/java` -> classes necessárias para o teste.
- `src/test/java` -> classes de teste JUnit.
